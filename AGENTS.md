# CrossMouse

Stripped-down Mouse Without Borders: one mouse and keyboard shared between a Linux and a Windows machine over LAN, paired by IP address.

### Issue tracker

Issues and wayfinder maps live as markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Single-context layout: one `GLOSSARY.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
